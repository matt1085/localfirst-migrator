Support

Best-effort support for LocalFirst Migrator on Bazzite KDE x86_64.

Public GitHub Issues are public.

Do not post any of the following in an issue, comment, or screenshot:

  • Stripe order / payment information, receipts, or last-four card digits
  • Email addresses or postal addresses
  • API keys, tokens, passwords, SSH private keys, or wallet seeds
  • Checkout session IDs or download URLs that contain session parameters
  • Private network details (LAN IPs, Tailscale names, VPN endpoints)
  • Unsanitized diagnostic logs or home-directory paths with personal data

Refund transaction identifiers also do not belong in public issues. Use the refund policy process instead.

How to contact support

Open a support request on the public repository for technical product issues:

Open a GitHub issue

Operational follow-up: private refund or purchase-identity handling currently lacks a dedicated private inbox on this site. Prefer Stripe’s customer receipt/support paths for payment identity; keep GitHub issues technical and sanitized. Adding a private refund contact without paid SaaS is a follow-up item for the operator.

Sanitizing diagnostic reports

  1. Prefer in-app Diagnostics → Export support report (designed to be sanitized).
  2. Before attaching any log or screenshot, search for and remove emails, IPs, hostnames, usernames, home paths, tokens, and session IDs.
  3. Replace machine names with labels like Desktop / Laptop.
  4. Never paste raw ~/.ssh, wallet, browser, or password-manager contents.

A support report may include product version, build identity, OS/image/architecture, adapter states, transaction IDs and phases, redacted errors, and peer link state without private keys.

In scope for v1

  • Install and launch issues on Bazzite KDE x86_64
  • Linking failures with clear identity or offline errors
  • Flatpak migrate, rollback, and manual sync behavior for supported apps
  • Interpreting dry-run and “not supported yet” rows

Out of scope

  • Migrating KDE, Homebrew, or Distrobox writes
  • Recovering deleted secrets (they are never migrated)
  • General Linux administration unrelated to the product
  • Problems caused only by unsafe third-party Flatpak remotes

Response expectation

Best-effort replies within about two business days for paid customers during launch. This is not a 24/7 operations center.
