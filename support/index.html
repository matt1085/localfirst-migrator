Support

Best-effort support for LocalFirst Migrator on Bazzite KDE x86_64.

How to contact support

Open a support request on the public repository:

Open a GitHub issue

Do not paste private keys, passwords, tokens, wallet data, or arbitrary home-directory files into an issue.

In scope for v1

  • Install and launch issues on Bazzite KDE x86_64
  • Linking failures with clear identity or offline errors
  • Flatpak migrate, rollback, and manual sync behavior for supported apps
  • Interpreting dry-run and “not supported yet” rows

Out of scope

  • Migrating KDE, Homebrew, or Distrobox writes
  • Recovering deleted secrets (they are never migrated)
  • General Linux administration unrelated to the product
  • Problems caused only by unsafe third-party Flatpak remotes

Support reports

From the application: Diagnostics → Export support report (sanitized).

A support report may include product version, build identity, OS/image/architecture, adapter states, transaction IDs and phases, redacted errors, and peer link state without private keys.

It must not include SSH private keys, GnuPG content, browser data, KDE Wallet or password-manager data, tokens, or arbitrary home files.

Response expectation

Best-effort replies within about two business days for paid customers during launch. This is not a 24/7 operations center.
