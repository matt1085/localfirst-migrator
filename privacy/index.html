Privacy

LocalFirst Migrator is designed to keep your setup local. This page describes product privacy behavior for version 1.0.

Last updated: 31 October 2026

Summary

  • No cloud account is required for core operation
  • Telemetry is off by default
  • Profiles store inventory and choices — not passwords or private keys
  • Secrets are never migrated or synchronized
  • This website does not use analytics trackers or advertising cookies

What the application does locally

LocalFirst Migrator runs on your computers. Scanning, planning, migration preview, supported Flatpak migration, rollback, and manual Flatpak sync are performed as local product operations.

What is never synchronized

  • SSH private material
  • GnuPG material
  • Browser cookies and sessions
  • KDE Wallet contents
  • Password manager data
  • Tokens, API credentials, signing keys, and recovery secrets

Peer linking

Pairing another computer uses a local network path. The product does not require a public listener or Funnel for normal operation.

This website

This marketing site is static content hosted on GitHub Pages. It does not set advertising cookies and does not load third-party analytics scripts.

GitHub, as the host, may process standard technical request data needed to serve the pages according to GitHub’s own policies.

Purchases

Online checkout is handled by Stripe via a hosted Payment Link. Stripe processes purchase information under its own privacy terms. LocalFirst Migrator does not need a cloud account for the software itself to operate.

Support reports

If you export a support report from Diagnostics, it should contain product version, build identity, platform details, adapter states, transaction IDs, and redacted error details. It must not include private keys, passwords, browser data, tokens, or arbitrary home files.

Contact

Privacy questions can be sent through the support page or by opening an issue on the public GitHub repository.
