How to move Flatpak apps to another Bazzite computer

You can do this with shell commands. LocalFirst Migrator exists for people who want a reviewed, previewable path for supported Flatpaks.

Manual approach (still valid)

Public Flatpak backup guides typically look like:

  1. Save installed refs: flatpak list --app --columns=installation,ref
  2. Save remotes: flatpak remotes --columns=name,url
  3. Optionally export overrides
  4. Copy ~/.var/app if you need application data
  5. On the new machine, re-add remotes and loop flatpak install

That works. It also means you are the migration planner, installer, and recovery plan.

LocalFirst Migrator approach (supported Flatpaks)

  1. Install LocalFirst Migrator on both Bazzite KDE x86_64 machines.
  2. Scan the source computer.
  3. Link the destination computer locally.
  4. Review rows: will install, already present, not supported yet, blocked for safety.
  5. Run preview / dry-run — confirm no changes were made.
  6. Apply supported Flatpak migration; verify; roll back while valid if needed.
  7. Optional: manual Flatpak sync with explicit conflict choices (never automatic in v1).

When the manual path is enough

  • You are comfortable with shell loops and Flatpak remotes
  • You only need a one-line list of apps and will reinstall casually
  • You are cloning a whole home or disk for other reasons anyway

When the product may be easier

  • You want a side-by-side review before anything installs
  • You want a dry-run gate and transactional install phases
  • You want rollback for supported Flatpak migrations
  • You prefer a packaged GUI over inventing your own checklist

Limits (do not skip)

  • KDE settings, Homebrew, and Distrobox writes are not yet supported
  • Secrets are never synchronized
  • Background sync is not enabled
  • This is not a complete Linux or complete Flatpak-userdata clone guarantee
