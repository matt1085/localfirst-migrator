Features

LocalFirst Migrator 1.0 helps you move supported Flatpak applications between Bazzite computers without guessing.

Included in v1

  • Workstation scan
  • Computer linking
  • Compare and migration plan
  • Dry-run with zero mutation
  • Supported Flatpak migration
  • Flatpak rollback and transaction history
  • Manual Flatpak sync with conflict choices
  • Machine-specific separation
  • Secret blocking by design
  • Packaged installer and uninstaller

Platform

Primary platform: Bazzite KDE, x86_64. Two machines can be linked over your local network path. The customer interface abstracts transport details.

Not included

  • KDE settings write migration
  • Homebrew migration
  • Distrobox recreation writes
  • Automatic background sync
  • Secret / password / key synchronization
  • Windows disk erase or dual-boot automation
  • Cloud backup
